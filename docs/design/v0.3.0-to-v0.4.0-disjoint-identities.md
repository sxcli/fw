# v0.3.0 → v0.4.0 — disjoint identities: an id contains at least one `/`

## What we want to change

1. The service-id grammar requires **at least one `/`** — an id is
   package-shaped or it is not an id. Single-segment ids
   (`"cherry"`) become registration-commit violations.
2. With that floor, id and alias grammars are disjoint by
   construction (aliases never contain `/`): one string can never
   name both a service's alias and another service's id. The
   pathological tie and its "say which" violation become
   unreachable. (The operator-facing flags stop mixing vocabularies
   altogether — see the explicit-control-vocabulary design, which
   removes `resolveRef` entirely.)
3. The spec's identity section states the rule; sxcli-vet keeps the
   stronger static check (begins with the *actual* import path) — the
   runtime now enforces the structural floor of it.

## Why

- Review (point 5, the resolveRef tie): one string naming service
  A's alias and service B's id forced a reported-but-not-resolved
  state through a clumsy triple return, and its first fix attempt
  was a nil-deref bug. Complexity that exists only because the
  grammars overlap on single-segment strings.
- The overlap is an oversight, not a decision: the grammar validated
  slash-separated segments with one segment as the degenerate case,
  while "id begins with the package's import path" was filed as
  vet-only. Every real import path contains `/`; the runtime could
  always have enforced that floor.
- What kept it alive is our own convenience: test fixtures and doc
  examples register `"app"`, `"dep"`, `"extra"`. The fallout of the
  mandate lands almost entirely on fixtures — the right direction.

## What we expect it to touch

- **fw**: the id grammar's single home (per the single-home-checks
  design: `internal/registry`, `identity.go` delegating) gains the
  `/` floor; the tie test becomes a grammar-rejection test.
- **Fixtures and docs**: every single-segment id in z_/x_ tests,
  README and spec examples becomes path-shaped
  (`"example.com/app"` or similar) — the bulk of the diff,
  mechanical.
- **completion**: its test fixtures likewise; no behavior change
  (aliases were already its operator currency).
- **sxcli-vet**: grammar mirror gains the same floor (ledger row
  moves with the single home); its "begins with import path" check
  unchanged and still stronger.
- **spec**: identity model section — the rule and its why.
- **Breaking**: any user binary registering single-segment ids —
  v0.4.0.
